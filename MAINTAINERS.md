# Maintainers

This file defines ownership and roles for **semRTI**, per the Technical Rulebook for
INFINITY Developers. Every repository must always have an active Champion.

## Champion

The Champion is the technical owner and accountability point for this repository. Responsibilities
span technical leadership, repository stewardship, code review and QA, contributor coordination,
security oversight, release management, ecosystem alignment, documentation ownership, and
long-term sustainability. Full definition: [docs/governance.md](docs/governance.md).

so the repository is never left without an active Champion.
