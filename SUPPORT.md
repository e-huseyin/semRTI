# Support

## Getting help

- **Usage questions**: check the [README](README.md) (installation, usage, FAQ) first.
- **Bug reports**: open an Issue in this repository. Include steps to reproduce, expected vs.
  actual behaviour, and your environment.
- **Feature requests**: open an Issue describing the use case and desired behaviour.
- **Security vulnerabilities**: do **not** open a public issue — see [SECURITY.md](SECURITY.md).

## Response expectations

This is a component of the INFINITY Ecosystem, maintained on a best-effort basis by its Champion
(see [MAINTAINERS.md](MAINTAINERS.md)). There is no guaranteed response time outside of
project-internal service level agreements, if any apply.

## Before asking

Please search existing Issues to avoid duplicates, and check whether `scripts/validate.sh` or the
CI pipeline already surfaces the problem you're seeing.
