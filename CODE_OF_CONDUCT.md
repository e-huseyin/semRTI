# Code of Conduct

This Code of Conduct applies to everyone participating in **semRTI** and, more broadly,
the INFINITY Ecosystem: contributors, maintainers, and the Champion alike.

## Our standards

Contributions to INFINITY are expected to uphold the ecosystem's core principles:

- **Openness** — contribute openly, unless explicitly agreed otherwise.
- **Transparency** — make development processes, design decisions, and version history publicly
  visible, recorded in this repository.
- **Reproducibility** — help others rebuild, run, and verify this work.
- **Security by design** — treat security as part of the work, not an afterthought.
- **Interoperability** — design for integration with the rest of the INFINITY Ecosystem.
- **Long-term sustainability** — write maintainable, well-documented code.

Examples of behaviour that contributes to a positive environment:

- Using welcoming and inclusive language.
- Respecting differing viewpoints and experiences, and disagreeing constructively.
- Giving and gracefully accepting constructive feedback in code review.
- Focusing on what is best for the component and the wider ecosystem.
- Recording discussion and decisions in the repository, not in side channels.

Examples of unacceptable behaviour:

- Harassment, insulting or derogatory comments, and personal or political attacks.
- Publishing others' private information without explicit permission.
- Submitting contributions that knowingly violate licensing, ethics, or data protection
  requirements described in this repository's documentation.
- Other conduct which could reasonably be considered inappropriate in a professional setting.

## Enforcement

Instances of unacceptable behaviour may be reported to the Champion listed in
[MAINTAINERS.md](MAINTAINERS.md). If the report concerns the Champion, escalate to the INFINITY
Technical Board (contact: nixon@storypact.com). All complaints will be reviewed and investigated
and will result in a response deemed necessary and appropriate to the circumstances.

The Champion is responsible for clarifying and enforcing standards of acceptable behaviour in
this repository, including the right and responsibility to remove, edit, or reject comments,
commits, code, issues, and other contributions that are not aligned with this Code of Conduct.
