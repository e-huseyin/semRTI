# Security Policy

## Reporting a vulnerability

If you discover a security vulnerability in **semRTI**, please report it privately
rather than opening a public issue.

- Email: huseyin.erdogan@unibo.it
- Include: a description of the vulnerability, steps to reproduce, affected version(s), and, if
  possible, a suggested fix or mitigation.

The Champion (see [MAINTAINERS.md](MAINTAINERS.md)) will acknowledge reports and coordinate a fix
as a high-priority responsibility. Please allow reasonable time for a fix to be released before
any public disclosure.

## Supported versions

| Version | Supported |
|---|---|
| 1.x | ✅ |
| < 1.0 | ❌ |

## Scope

This policy covers the source code, configuration, and dependencies declared in this repository.
It does not cover third-party services this component may integrate with (e.g. RelightLab,
SPARQL Anything) unless the vulnerability originates in how this component uses them.
